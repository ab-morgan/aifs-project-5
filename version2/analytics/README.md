# Analytics Layer

Provides optional analytics utilities.

Modules:

job_family_clustering.py
  KMeans clustering of job embeddings.

seniority_normalization.py
  Maps raw titles to canonical seniority buckets.

mobility_scoring.py
  Computes mobility score based on similarity, seniority delta, job family match.

Purpose:
Supports future dashboards, insights, and advanced matching logic.
