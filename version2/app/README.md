# Streamlit Runtime

The runtime UI lives in version2/app/.

Features:
- Resume upload (PDF/DOCX)
- Resume text input
- Embedding generation
- Similarity search
- Job match display
- Dataset stats sidebar

Run:
streamlit run app/app.py

Components:
- sidebar.py (resume input)
- job_match_panel.py (match results)
- stats_panel.py (dataset stats)
